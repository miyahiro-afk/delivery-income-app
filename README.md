# デリログ — フードデリバリー収支管理

スマートフォン向けの個人用 Web アプリ。ログイン・課金はありません。

## 開発

Node.js 20.19+ または 22.12+（この環境では 24）を使用します。

```sh
npm ci
npm run dev
```

## 検証・ビルド

```sh
npm test
npm run build
# 開発サーバー起動中に実行。/usr/bin/chromium が必要です。
npm run test:e2e
```

`dist/` が静的サイトの公開用ファイルです。`npm run preview` でビルドを確認できます。

## 機能

- 日付ごとに1記録。Uber Eats・出前館・Rocket Now・その他の売上
- 稼働時間（小数の時間、例：3時間30分は3.5）・配達件数
- ガソリン代・レンタル代・駐車料金・食費・その他の経費
- 利益＝売上−経費、時給＝利益÷稼働時間、1件あたり＝売上÷配達件数
- 月間売上目標70万円：残額、達成率、今日を含む月末までの日数と1日あたりの必要額（1円単位で切り上げ）。達成後は残額・必要額0円
- 今日・今月の集計、サービス別の合計、月別履歴、編集・削除
- 時間または件数が0の場合、対応する単価は「—」を表示

## データ保存

記録は同一端末・ブラウザー・URLの localStorage に保存します。サーバー送信や端末間同期はありません。ブラウザーの閲覧データ削除、シークレットモードの終了、URLの変更に注意してください。バックアップ機能は初期版にはありません。保存に失敗すると入力画面に留まり、既存の破損データは上書きしません。

## スマホのホーム画面に追加

ホーム画面用アイコンと Web App Manifest を用意しています。公開された HTTPS の URL をスマホで開いてください。このクラウド開発環境の localhost はスマホから開けません。`dist/` を静的ホスティングに公開する必要があります。

- iPhone：Safari で開く → 共有 →「ホーム画面に追加」→「追加」。表示される場合は「Webアプリとして開く」をオンにします。
- Android：Chrome で開く → メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」。名称はブラウザーのバージョンにより異なります。

アイコンから開くと対応ブラウザーでは単独のアプリ画面で起動します。オフライン起動は未対応です。記録はブラウザーの保存領域に依存するため、追加前後で既存の記録が表示されるか確認してください。公開先URLを変更すると保存データは共有されません。

## GitHub Pages で公開

[初心者向けの公開手順](GITHUB_PAGES.md) を参照してください。main 更新時に `.github/workflows/deploy-pages.yml` がテスト・ビルド・公開を行います。GitHub 側で Pages の Source を GitHub Actions に設定してください。Private リポジトリは対応する有料プランが必要です。

ビルドは `/delivery-income-app/` 用です。公開前のローカル確認は `npm run build` → `npm run preview -- --port 4173`、ブラウザー検証は `APP_URL=http://127.0.0.1:4173/delivery-income-app/ npm run test:e2e` で実施できます。

## ホームの目標・借金返済管理

- 月の売上目標はホームで変更できます。月ごとに保存し、未設定の月は70万円です。
- 今日の目標＝（月の目標−昨日までの今月の売上）÷今日を含む月末までの日数（1円単位で切り上げ）。今日あと必要な額＝今日の目標−今日の売上、最低0円です。未来の日付の売上は今日の目標計算に含みません。
- 借金は管理開始時の残額を登録し、実際の返済額と日付を追加します。残額＝登録額−返済額合計。返済の誤入力は削除して登録し直せます。
- 返済は売上・経費・利益とは独立しています。利息の自動計算や複数の借入先別管理はありません。追加借入・利息がある場合は登録額を調整してください。
- 目標・返済記録もブラウザー内に保存されます。既存の売上記録は保持します。
